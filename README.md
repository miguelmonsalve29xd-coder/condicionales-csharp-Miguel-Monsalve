## Descripción del proyecto

Este proyecto contiene la solución al taller de problemas de estructuras condicionales en C#. El objetivo es practicar la lógica de programación mediante ejercicios que utilizan estructuras como `if`, `else`, `switch`, operadores ternarios y validaciones de datos.

Los ejercicios están organizados en 30 proyectos independientes dentro de una misma solución llamada `Condicionales.sln`.

## Estructura del proyecto

Cada ejercicio cuenta con su propio proyecto de C# y contiene los archivos necesarios para ejecutarlo y documentarlo.

- `Program.cs`: contiene el código fuente del ejercicio.
- `ProblemaXX.csproj`: archivo de configuración del proyecto.
- `README.md`: explica la estructura condicional utilizada y la razón de su elección.
- `evidencias/salida.png`: captura de pantalla que demuestra la ejecución del programa.

La solución principal `Condicionales.sln` reúne los 30 proyectos.

## Requisitos

- Tener instalado el SDK de .NET.
- Tener instalado Visual Studio Code o un editor compatible.
- Tener Git instalado para administrar los cambios del proyecto.

## Cómo ejecutar los ejercicios

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir una terminal en la carpeta raíz.
3. Ejecutar el ejercicio que se desea probar. Por ejemplo:

   ```bash
   dotnet run --project Problema21
   ```

4. Cambiar `Problema21` por el nombre del proyecto que se desea ejecutar.
5. Ingresar los datos solicitados y comprobar el resultado.

Para compilar toda la solución, ejecutar:

```bash
dotnet build Condicionales.sln
```
